TLS certificate

This program terminates TLS; it does not issue or renew anything. Point it at a certificate you generated elsewhere. Both files are checked here, in the same context the service will open them from.

Both files are copied into this machine's data directory, so you do not have to put them anywhere the service can already read. A certificate is opened when the listener binds, so this takes effect after a restart.

After the restart this port speaks HTTPS only. Plain http:// to the dashboard port stops working: the browser will say the connection was reset or the server sent gibberish, and neither is a fault. Use https:// from then on, and update any bookmark or home screen shortcut that still says http://. The report port is unaffected and stays plain HTTP.
